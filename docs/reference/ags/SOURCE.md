# AGS code lists

`ABBR.csv`, `UNITS.csv`, `DATATYPES.csv` and `ELRG.csv` are the AGS Data Format code lists, downloaded unchanged on 2 November 2026 from the AGS website: https://www.ags.org.uk/data-format/

© The Association of Geotechnical and Geoenvironmental Specialists (AGS). They are included here only so that the AGS checker in this non-commercial portfolio project can run. Always get current lists from the AGS website.

Every entry has an AGS status:

| Status | How the checker treats a file that uses it |
|---|---|
| Approved | OK |
| Accepted | Note |
| Proposed | Warning |
| Deprecated | Warning |
| Declined | Error |

Only rows valid for AGS 4.2 are used (`Version` column). The AGS 4.2 specification PDF is not included. It can be downloaded free of charge from the same page.
